# v0.1.0 — Quest 3 Preview

First public standalone preview of Animal Crossing VR/MR for Meta Quest.

## Highlights

- Standalone Quest APK with native OpenXR stereo rendering and 6DoF head tracking.
- Custom Animal Crossing VR launcher with persistent user-selected ROM access.
- Validates Animal Crossing USA Rev 0 (`GAFE01`, revision 0); no ROM is bundled.
- Tabletop mixed-reality mode enabled by default with Quest passthrough.
- Runtime right-stick-click toggle between Tabletop MR and immersive VR camera.
- Passthrough automatically pauses outside Tabletop MR mode.
- Two-hand tabletop move / rotate / zoom controls.
- Stabilized Animal Crossing camera and smoother acre transitions.
- Extended actor/display-list draw range and VR far-plane handling.
- OpenXR runtime hand mesh in tabletop mode, rendered white, with tabletop clipping/occlusion.
- VR-safe HUD/menu presentation and Quest Touch GameCube defaults.
- Public reproducible Quest build script with no developer-specific paths.

## Installation

1. Download `AnimalCrossingVR-Quest3-v0.1.0.apk` from the release assets.
2. Sideload it to a Meta Quest 3 / Quest 3S.
3. Open **Animal Crossing VR**.
4. Press **Select ROM** and select your own legally obtained Animal Crossing USA Rev 0 image.
5. Press **Launch Animal Crossing VR**.

## Important

This release contains no Nintendo ROM, game assets, audio, textures, or proprietary game data.

This is an experimental preview. Rendering and MR edge cases may still exist.
